# Kenza Lbasri - Cybersecurity Portfolio

A modern, high-impact personal portfolio website for a cybersecurity student, built with Next.js and Tailwind CSS. The design embodies a professional, slightly futuristic, and security-themed aesthetic with a dark mode, neon accents, and subtle cyber/terminal elements.

## Features

- **Modern Tech Stack:** Built with Next.js, React, and styled with Tailwind CSS for a highly performant and responsive experience.
- **Cybersecurity Aesthetic:** Dark theme with neon green/blue accents, terminal-inspired elements, and subtle animations.
- **Fully Responsive:** Adapts seamlessly to mobile, tablet, and desktop devices.
- **Component-Based:** Clean and modular code structure for easy maintenance and scalability.
- **Key Sections:**
    - **Hero:** Impactful introduction with a typing effect and call-to-action.
    - **About:** Professional bio highlighting cybersecurity passion.
    - **Skills:** Categorized display of technical skills.
    - **Projects:** Showcase of cybersecurity projects with descriptions and tech stacks.
    - **Experience/Learning:** Certifications, labs, and coursework.
    - **Contact:** Easy ways to connect via email, GitHub, and LinkedIn.
- **Smooth Navigation:** Scroll-based navigation between sections.
- **Subtle Animations:** Hover effects, fade-ins on scroll, and dynamic text enhance user experience without being overwhelming.

## Getting Started

Follow these instructions to get a copy of the project up and running on your local machine.

### Prerequisites

Make sure you have Node.js and npm (or yarn) installed on your system.

- [Node.js (LTS)](https://nodejs.org/en/)
- npm (comes with Node.js) or [Yarn](https://classic.yarnpkg.com/en/docs/install/)

### Installation

1.  **Clone the repository:**

    ```bash
    git clone https://github.com/kenzalbasri/cybersecurity-portfolio.git
    cd cybersecurity-portfolio
    ```

    *(Note: The GitHub link provided is a placeholder. You would replace `https://github.com/kenzalbasri/cybersecurity-portfolio.git` with your actual repository URL once created.)*

2.  **Install dependencies:**

    Using npm:
    ```bash
    npm install
    ```

    Using yarn:
    ```bash
    yarn
    ```

### Running Locally

To start the development server:

Using npm:
```bash
npm run dev
